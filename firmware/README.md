# Firmware

All programs run on the Adafruit QT Py M0 under CircuitPython.

| Folder | What it does | Roadmap phase |
|---|---|---|
| [`bench-test-1/`](bench-test-1/) | Measures glare-cut of an unpowered cell against polarized sunglasses | 1 |
| [`bench-test-2/`](bench-test-2/) | Drives the cell at a set voltage to find screen mode, by eye or with the sensor | 2 |

Planned: the glasses firmware with the hardware-timed three-level drive, button handling and
watchdog (phase 3 onward).
