# Frame

Nothing here yet. This folder will hold the printed frame for the wearable first version
(roadmap phase 3): two 36 mm Adafruit liquid crystal squares with the front polarizer peeled,
a world-side shield, an eye-side 0.5 mm polycarbonate window, and a soft gasket holding the
stack against an eye-side lip. The electronics ride in a clip-on box at this stage.

Parts already bought:

- Stainless plate hinges, about 15 mm, three knuckles, two screw holes per leaf.
  Wires can't pass through these, so the cable runs outside the hinge.
- An eyeglass repair kit (screws, nose pads, drivers).

Hinge pockets wait on caliper measurements of the hinges.

Suggested layout once files exist:

- `cad/` editable source (for example Fusion or Onshape exports, STEP)
- `stl/` print-ready files, named with a version letter, such as `frame-v0a.stl`
